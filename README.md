# Misery Inc. Minimal Website

This version intentionally preserves the ORIGINAL image-free minimalist landing page: charcoal background, bone typography, sage and violet accents, giant hero type, three cards, and a short social section.

## Publish with GitHub Pages
1. Upload all files from this folder to the repository root, including `index.html`.
2. Settings > Pages > Deploy from a branch > main > / (root).
3. Set `miseryinc.club` as your custom domain; configure DNS at your registrar and enable HTTPS.

## BEFORE collecting signups
1. In `site.js`, set `GOOGLE_FORM_URL` to the public respondent link and `CONTACT_EMAIL` to a working address.
2. In `privacy.html`, replace the operator/contact placeholders and ensure all stated practices are accurate.
3. Configure the Google Form with only necessary fields, clear affirmative consent, privacy policy link, and a truthful explanation of future promotional emails. Do not enable file uploads or collect sensitive information.
4. Set up an email service with an unsubscribe mechanism and the legally required sender details before sending marketing messages.
5. Check Google Forms settings: avoid requiring Google login unless necessary; do not make responses publicly visible; restrict access to collected data.
6. Verify policies, keyboard navigation, mobile layout, and screen reader usability. These are drafts, not a certification or legal opinion.

No analytics or advertising trackers are included. The cookie banner stores a browser-local consent preference; it does not activate trackers. No email information is collected by this static site until you connect the form.
